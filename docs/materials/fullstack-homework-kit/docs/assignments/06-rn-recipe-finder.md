# Исходное задание — Assignment 6: Recipe Finder

## Статус

Assignment 6. В системе указано: `To do: Make a submission` — работу требуется сдать.

## Что требуется

- Создать приложение, которое получает рецепты по введённому ингредиенту из MealDB: <https://www.themealdb.com/api.php>.
- Показать в `FlatList` название и миниатюру каждого найденного рецепта.
- Свериться с документацией API. В условии приведён пример запроса для ингредиента `tomato`: <https://www.themealdb.com/api/json/v1/1/filter.php?i=tomato>.

## Ожидаемый результат

Пользователь вводит ингредиент и запускает поиск. Приложение получает подходящие рецепты из MealDB и выводит их списком, показывая название и миниатюру каждого рецепта.

## Что сдавать

В системе требуется отправить работу (`Make a submission`). Формат сдачи, состав файлов и необходимость прикладывать ссылку на репозиторий в исходном условии не указаны.

- Скриншот в условии показывает пример внешнего вида и результата поиска; требование точно повторить оформление отдельно не сформулировано.
- Обработка ошибок, загрузки и пустого результата, а также требования к тестам в исходном условии не описаны.
